# Feature review — 5 October 2026

This review compares the requested list with the current code. Priority is a product judgment for the first free personal-finance release.

| Feature | Current coverage | Suggested priority |
| --- | --- | --- |
| Dashboard | Monthly financial totals, cash flow, savings rate, trends, spending detail and goal progress | Must; implemented |
| Income | Income entries and customizable categories for salary, freelance, bonus and other sources | Must; implemented |
| Expenses | Quick daily expense entry, dated entries, notes and editing | Must; implemented |
| Categories | Custom categories and optional expense subcategories | Must; implemented |
| Monthly budget | Independent monthly overall expense limit | Must; implemented |
| Category budgets | Monthly limits for expense categories | Must; implemented |
| Recurring expenses | No recurring schedule or automatic transaction creation | High; next addition, not a blocker for the manual-tracking first release |
| Bills and reminders | No upcoming-payment list, due dates or notifications | High; build with recurring schedules |
| Savings goals | Aggregate monthly savings target and emergency-fund progress; savings categories can describe purposes. Individual goal amounts, deadlines and per-goal progress are missing | High; partially implemented |
| Reports and analytics | Monthly trends, category comparisons, spending breakdown and Excel summaries | Must; implemented for the first release |
| Search and filters | Transaction text search, category, month and year filters | Must; implemented |
| Debt tracking | No loan, lender/borrower or repayment model | V2; optional for first release |

The last pasted item is truncated at “Sm” and cannot be assessed.

Recommended order: recurring expense schedules with upcoming bills, then named savings goals, then debt tracking. Scheduled expenses need duplicate prevention and a clear choice between reminders and automatic recording. This is a review, not authorization to implement those additional features.
